## Verdict

The draft is unusually well-provenanced — every ask carries n and a date, keys are stable and used consistently, the HTML is clean, and the ledger is honest — but it is not yet actionable from the TL;DR and it contradicts itself in the two places a player would actually lose value: the keep/sell/leave vocabulary drifts between §3 and §5 (so the same 1.0-Ist Archon is both "sell" and "floor"), and §5's "keep/Larzuk" labels on max-5/6 bases invert the guide's own "wrong count is final" rule. Closure is good for whites, blues, charms, jewels, runes and gems but has one large hole (rare armor/weapons have no rule) and several half-rules keyed on information invisible on the ground. The fixes are mostly mechanical: make §5 the single price/verdict source with one bucket per row, define the action words once, add the missing rare/Superior-<15/0os-plain lines, put the Larzuk warning in a warnbox, and rewrite the TL;DR as the §3 group list plus "new game per Pindle". After those, a second pass (fact-check lens) should find it stable.
