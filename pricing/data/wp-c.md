# WP-C - Anya shop checklist (Hell, and Nightmare) - 2026-09-18

**Arithmetic used everywhere:** shop **ilvl = clvl + 5**, cap 99 (purediablo 2023-02-22; Hastmannen ~2021). So clvl 20 -> ilvl 25 (magic-only from here) · 55 -> 60 · 70 -> 75 · 75 -> 80 (+3 skill-tree prefix per BMAY) · 94 -> 99 (max exceptional/elite chance). Exceptional/elite chance in Hell = ((ilvl*128)+5000)/100k and ((ilvl*16)+1000)/100k: 15.2 % + 2.3 % at ilvl 80, 17.7 % + 2.6 % at ilvl 99 (BMAY/purediablo). Nightmare exceptional = ((ilvl*64)+4000)/100k, no elite in NM. Affix level = ilvl - qlvl/2 (purediablo; maxroll staff-mods 2026-02-10) - thresholds per affix were not fetched, so the clvl column repeats what the sources say. Values: see WP-B / WP-H unless a source gives one (all "orientation").

## What Anya does NOT sell (Hastmannen ~2021; purediablo 2023-02-22; d2io NPC page)
- **Ethereal** anything. **White or socketed** items once ilvl >= 25 (clvl >= 20) - magic only. **Rares/uniques/sets** never from the shop (gamble only).
- **Elite bases in Nightmare** (elite upgrade formula exists only for Hell); in Hell elite bases first appear from A3 on, so Anya can - but items tagged "hell upgrade" never roll exceptional/elite.
- Item types whose **qlvl > ilvl** (e.g. Runic Talons qlvl 81 need ilvl >= 81).
- Claws outside the **Blade/Greater/Runic Talons** and **Scissors Katar/Quhab/Suwayyah** classes (purediablo). Staff mods never on normal-quality claws.
- Pre-RotW stock list (d2io): "Armor, Weapons (Katars, Throwing Weapons), Keys and Arrows" - no staves/wands/scepters (Malah), no daggers/grimoires listed. RotW changes to this list: unverified (below).

## Refresh loop (as the sources state it)
1. Anya + the Red Portal to Nihlathak's Temple are SW of the Harrogath waypoint, available after "Prison of Ice" (maxroll Pindle guide 2026-02-10). The portal "no longer disappears in D2R" (maxroll tips 2023-11-22).
2. Trade -> weapons tab (claws, throwing weapons) / armor tab (gloves, armor). Claw trick: keep dex at exactly 55 so every exceptional/elite claw shows red and only red claws need a mouse-over (BMAY).
3. Nothing good -> "go to the red portal and go through and quickly back again. If you are quick you won't wake up any of the zombies. This refreshes what she has to sell. Rinse & repeat" (purediablo 2023). BMAY: "Keep Nihlathak's portal open and run between it and Anya"; with Burst of Speed + FRW + Harmony ~20 checks/min, 3.5 claws/refresh, ~4,200 claws/h - **per source, verify**.
4. No refresh while another player is in town (Hastmannen). Ours (not a source): each Pindle run already passes the portal, so check Anya once per run.
