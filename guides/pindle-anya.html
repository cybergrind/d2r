Rejected ideas (and why)
  1. Shop a white 4-socket armor at Anya. Vendors sell white/socketed items only up to ilvl 25 (clvl 20); from ilvl 25 on it is magic only (Hastmannen ~2021; purediablo 2023). The only 4os armor Anya can show after clvl 20 is a magic Jeweler's roll (AN-armor-whale). Enigma-type white bases come from drops.
  2. Use WP-A demand weight as a price. Flail / Crystal Sword / Diadem / Mage Plate top the demand list (weight 41) yet their white markets are floor (Flail n=53 0.08→0.67 Ist; CS 5os n=27 0.2→0.79; white Diadem n=2). Supply decides; only Superior ≥15 ED, ethereal (merc) or the 45@ automod carry value (WP-B).
  3. Use the user's URL filter literally (prop_1076Min=1) — it is Dragon Flight, 0 base listings; replaced by sockets + ethereal (see assumptions).
  4. Scrape the Traderie website / pass its bool filters to the API. The site is a JS shell; the API answers without a token but ignores prop_738/799/800 — filter client-side (plan, verified 2026-09-18).
  5. Traderie price-history endpoints return 401; asks from live listings plus diablo2.io sold rows are all we get.
  6. Read a Traderie rune/gem stack ask as per-unit. WP-F confirmed per-stack on 322 listings ("Ist ×11 → 1 Jah"); divide by amount. Base listings are the opposite: per unit (quantity = stock).
  7. Use maxroll's 2024 value tiers as prices. Pre-RotW and Ladder-start oriented; used only for affix names and categories.
  8. Pick up every gray elite base regardless of list, eth or Superior prefix. A drop with the wrong socket count is final (cube needs an unsocketed base; Larzuk gives the ilvl-86 max), and plain 4os Dusk/Monarch or 5–6os PB/BA ask 0.08–1.0 Ist (n=10–53) — not worth a portal (PK-leave-white).
  9. Larzuk every 0os base. On a base whose ilvl-86 maximum exceeds the runeword count (Giant Thresher 6 vs Insight 4) Larzuk destroys the value irreversibly; see the warnbox above §3.
